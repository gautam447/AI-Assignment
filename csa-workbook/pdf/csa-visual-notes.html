01 · Platform & navigation

teal domain · 7% · vocabulary for everything else

What is ServiceNow?

Cloud aPaaS — they host it, you configure it.

Multi-instance (not classic multi-tenant DB). Each customer = dedicated app + database.

  • Landscape: PROD + DEV/TEST
  • Clone copies prod → subprod and overwrites the target
  • Now Support (HI) = upgrades, some plugins, clones, cases
  • PDI = free student instance + demo data

03 · Collaboration — lists & forms

amber domain · 20% · ‘what happens when I click X’

List anatomy

  • Row = record · Column = field
  • Breadcrumbs = the filter
  • Filter = Field + Operator + Value
  • Right-click menus: title / column / cell / row / form
  • Double-click cell = list edit (if allowed)
  • Tags ≠ categories ≠ user criteria

Form anatomy

  • Header buttons · sections · fields
  • Related lists (children pointing here)
  • Activity stream + User Presence
  • Reference field stores sys_id, shows name
  • Dot-walk: Caller → Department → Name
  • View = named layout (Default ≠ Self Service)

The save-button board (write this on your exam scrap paper)

actionnew record?form closes?when
SubmitNEW recordYES — closescreating
Updatesame recordYES — closesexisting
Savesame (or first insert)NO — stayskeep working
InsertNEW sys_id (clone values)YESform menu
Insert and StayNEW sys_idNO — staysform menu
⚠️ Insert ≠ Submit
Insert from an existing record clones it into a new row. Update ≠ Save (close vs stay).
comments vs work notes
Additional comments = caller can see (and often gets emailed).
Work notes = fulfiller only.
missing field?
Check view first, then UI Policy, then field ACL, then dictionary. Don't jump to ACL every time.
Form Designer = canvas · Form Layout = slushbucket · same resultD3a

05 · Data schema

violet domain · 30% · if you only master one chapter, this one

Everything is a record in a table

Basetask, cmdb
Child / extendincident is-a task
Custom globalu_...
Scoped appx_company_app_...

sys_id = 32-char GUID (real key). Number like INC0001 is just a label.

How tables relate

  • Extension — Extends table field
  • One-to-many — reference field on the many side (Incident.caller → User)
  • Many-to-many — join table (task_ci)

Visualize with the Schema Map (Tables & Columns). Dictionary = field metadata. Dictionary override = change a parent field on a child only.

05 · Import, CMDB, CSDM, security

violet continued — the rest of the 30%

Import Sets

Excel / CSV / JDBC / LDAP
→
staging table
→
Transform Map
→
target table
official definition
A transform map relates Import Set fields to fields on an existing table.
coalesce
Match key → UPDATE. No match → insert. No coalesce → duplicates. Use email / employee # / serial.
💡 UI Policy vs import
UI Policies do not run on transform. Use a Data Policy (or dictionary mandatory) if Excel must obey the rule.

CMDB + CSDM

cmdb_ci
configuration items (tangible + intangible)
cmdb_rel_ci
relationships · Dependency Views
CI Class Manager
classes, identity, hierarchy

Discovery = bottom-up, needs MID Server in your network.
Service Mapping = top-down from a service entry point.
CSDM = common vocabulary / best-practice model — not “a plugin that replaces ITSM”.

Foundation users/locations (usually not CI relationships)
